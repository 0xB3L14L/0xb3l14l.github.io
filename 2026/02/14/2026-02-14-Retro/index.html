Retro

Creado2026-02-14|Actualizado2026-02-16|VulnlabActive DirectoryEasy

Enumeración Inicial

Se inicia con un reconocimiento de puertos estándar para identificar los servicios activos.

Nmap

SMB Anom auth

Al revisar los recursos compartidos.

Se encuentran dos shares, Notes y Trainees. Y al revisar, solo se puede leer Trainees.

Dentro hay una nota.

Info:

  • Los trainees utilizan solo una cuenta que es compartidad.
  • Contraseña puede ser debil o predecible.

trainee

Probamos las credenciales trainee:trainee y funcionan. Y este usuario puede leer el share Notes.

Dentro hay un archivo llamado ToDo.txt

Info de la nota:

  • Posibles usuarios: Thomas y James
  • Hay una machine pre created computer account
  • Se menciona un software bancario antiguo

User Enum

Se procede a enumerar usuarios.

Computer Enum + userAccountCrontol

Y computadoras.

IMPORTANTE

La cuenta de máquina BANKING$ tiene un userAccountControl de 4128. Esto indica que tiene los flags PASSWD_NOTREQD y WORKSTATION_TRUST_ACCOUNT, típico de cuentas pre-creadas sin uso.

Timeroasting

Ejecutamos un ataque de Timeroast para consiguir los hashes del ms-sntp.

Hay dos hashes pertenecientes a los rid 1000 y 1106, para saber a cuál pertenecen se utiliza netexec junto con –rid-brute

RID:

  • 1000 = DC$
  • 1106 = BANKING$

Se puede intentar crackear estos hashes, pero más rápido seria en adivinar la contraseña de BANKING$.

BANKING$

Al ser una cuenta pre-creada, la contraseña suele ser el nombre de la cuenta.

Logramos autenticarnos, pero recibimos un error STATUS_NOLOGON_WORKSTATION_TRUST_ACCOUNT, lo que significa que debemos cambiar la contraseña antes de poder usarla.

ESC1

Ya con el control de BANKING$, Se busca si hay plantillas vulnerables.

Se identifica una.

La plantilla RetroClients, la cual es vulnerable a ESC1 (Enrollee Supplies Subject). Esto nos permite solicitar un certificado para cualquier usuario, incluido el Administrador.

Primero se obtiene el SID del administrator.

Ahora para explotarlo, se debe solicitar el certificado con el upn y sid del administrator.

Se autentica para obtener tanto el ccache como el NT hash.

Ya teniendo el hash, se puede conseguir una shell como el Administrador.

Resumen

SMB anónimo (Trainees) → credenciales de trainee en notas → enumeración LDAP (UAC 4128) → identificación de cuenta pre-creada BANKING$ → Timeroasting + crack de contraseña por defecto (banking) → cambio de password vía kpasswd → AD CS (ESC1) en plantilla RetroClients → suplantación de administrator mediante SAN UPN/SID → obtención de Hash NT → WMIExec → Administrator (Domain Admin).
