Retro

Created2026-02-14|Updated2026-02-16|VulnlabActive DirectoryEasy

Initial Enumeration

It starts with a standard port scan to identify active services.

Nmap

SMB Anom auth

When reviewing shared resources.

Two shares are found, Notes and Trainees. And upon checking, only Trainees can be read.

Inside there is a note.

Info:

  • The trainees use only one shared account.
  • Password may be weak or predictable.

trainee

We test the credentials trainee:trainee and they work. And this user can read the Notes share.

Inside there is a file called ToDo.txt

Note info:

  • Possible users: Thomas and James
  • There is a pre-created machine computer account
  • An old banking software is mentioned

User Enum

User enumeration proceeds.

Computer Enum + userAccountCrontol

And computers.

IMPORTANT

The machine account BANKING$ has a userAccountControl of 4128. This indicates it has the flags PASSWD_NOTREQD and WORKSTATION_TRUST_ACCOUNT, typical of pre-created unused accounts.

Timeroasting

We execute a Timeroast attack to obtain the ms-sntp hashes.

There are two hashes belonging to rid 1000 and 1106, to know which they belong to netexec is used with –rid-brute.

ID:

  • 1000 = DC$
  • 1106 = BANKING$

You can try to crack these hashes, but it would be faster to guess the password for BANKING$.

BANKING$

Since it is a pre-created account, the password is usually the name of the account.

We managed to authenticate, but we received an error STATUS_NOLOGON_WORKSTATION_TRUST_ACCOUNT, which means we must change the password before we can use it.

ESC1

With control of BANKING$, we look for vulnerable templates.

One is identified.

The RetroClients template, which is vulnerable to ESC1 (Enrollee Supplies Subject). This allows us to request a certificate for any user, including the Administrator.

First, the administrator’s SID is obtained.

Now to exploit it, the certificate must be requested with the administrator’s UPN and SID.

Authentication is done to obtain both the ccache and the NT hash.

Having the hash, a shell can be obtained as the Administrator.

Summary

Anonymous SMB (Trainees) → trainee credentials in notes → LDAP enumeration (UAC 4128) → identification of pre-created account BANKING$ → Timeroasting + cracking default password (banking) → password change via kpasswd → AD CS (ESC1) in RetroClients template → administrator impersonation via SAN UPN/SID → NT Hash obtained → WMIExec → Administrator (Domain Admin).
